# Workman 0.6.3

Fixes Windows REPL startup failing with “The operation is not supported” and
evaluation failing to resolve the session's in-memory modules.

The REPL now uses a native Windows equivalent of cbreak mode and understands
Windows Terminal's extended key events, including Shift+Enter. Windows Terminal
also gets Workman's truecolor highlighting when `COLORTERM` is unset.

`wm watch` now tolerates a Windows program exiting just as a file change asks it
to stop, instead of crashing with Access Denied.

Windows test coverage now uses portable file paths, handles already-exited watch
processes during cleanup, and checks the intended C integer literal conversions.

Update the CLI and VS Code extension to 0.6.3. Restart open REPLs to use the fixes.
