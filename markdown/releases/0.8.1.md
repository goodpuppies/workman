# Workman 0.8.1

This patch makes `wm sml` work from the published package.

- `wm sml` failed in 0.8.0 with `Module not found` for `subset_host.js`: the bundled translator
  imported its host adapter by a path that existed only in the release checkout. It now imports
  the adapter the package ships, and a test keeps the bundle free of absolute file paths.

Update the CLI and VS Code extension together; there are no other changes from 0.8.0.
