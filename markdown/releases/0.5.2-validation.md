# 0.5.2 release preparation

Prepared locally on Windows, 2026-10-28. CLI and VS Code extension manifests and the
extension lockfile are synchronized at 0.5.2. Validation below preceded the release commit,
tag, and push.

## Validation

- `deno task check`: passed.
- `deno task test`: 1,232 passed, 3 failed, 2 ignored. The full run includes all six actual
  WebGPU rendering cases. All three failures subsequently passed together in a targeted
  rerun against the final manifests and configured C-header include paths.
  - The bare `stdio.h` test initially lacked system headers. It passes using
    `WM_C_HEADER_INCLUDE_DIRS` with Zig 0.16.0's `lib/libc/include/any-windows-any` and
    `lib/libc/include/generic-mingw` directories, separated by a semicolon.
  - Two CLI version-output assertions initially used the 0.5.1 JSON module cached when
    the full suite started, while child processes read the subsequently updated 0.5.2
    manifest. Both pass against the final consistent version.
- Combined final rerun: 3 passed, 0 failed; filter
  `/bare system headers|prints help with no arguments|deno.json version/` over
  `tests/c_header_aro_test.ts` and `tests/cli_test.ts`.
- `deno task generate`: passed; parser reached a fixed point after one stage.
  Parser, libraries, and semantic golden remained unchanged. Unrelated native extractor
  rebuild differences were restored to the previously tracked binaries; no native source
  changes are part of this release.
- `deno task c-header:check`: passed after restoring those binaries; all six platform
  artifacts match source, resources, and checksums.
- `npm --prefix editors/vscode run package`: passed after final generation/restoration.
  This includes extension TypeScript checking and client/server bundling.
- VSIX inspected: manifest version 0.5.2; annotation comparison disabled by default;
  client configuration and bundled server both include the comparison option.
- `deno publish --dry-run --allow-dirty`: passed; no publication performed.
- `git diff --check`: passed.

The full suite was not rerun a second time; its three failures were rerun together and
passed as described above. Logs are retained under gitignored `research/release-0.5.2-*`.
