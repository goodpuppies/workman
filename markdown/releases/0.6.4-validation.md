The initial full run reported **1,665 passed, 23 failed, 25 ignored**. Three failures were caused by
the new JS-definition test changing process-wide cache environment variables. That redirected
parallel CLI subprocesses into a temporary directory that the test removed. Commit `d8ccd0f` removes
the environment mutation. The following run exposed the missing `homedir` permission required by the
normal cache path; commit `91bdf85` grants only that lookup. A parallel rerun of JS-definition, CLI,
and library tests now reports **101 passed, 0 failed**. The final full-suite log is
`/tmp/wm-release-0.6.4-tests-verified.log`.

All 20 remaining failures reproduce on an untouched `git archive 4b1c60c` checkout using the same
machine and toolchain: **0 passed, 20 failed, 170 filtered out** in the selected failing cases. This
comparison establishes that they predate the feature/fix commits listed above; it does not make them
acceptable release gates. The baseline log is `/tmp/wm-release-baseline-remaining.log`.

## Follow-up fixes

- `22cfcfa`: preserve explicit deep reflection before generic-call rewriting. This restores concrete
  `Deno.dlopen` signatures and fixes the associated SDL/GPU and hover failures. The affected
  regression groups pass (77 tests).
- `82a4600`: reject unsupported callable signatures before property fallback. Iterator methods no
  longer silently return function values instead of reporting an unsupported result shape.
- `cfb2de7`: align FFI tests and the webhook example with receiver safety and explicit method-value
  invocation. Use scalar `abs` to keep the C wildcard precedence test independent of private libc
  stream layouts. The affected compiler/FFI/example groups pass (112 tests, 3 ignored).
- Webhook localhost simulation passes: signature verification, request handling, local mock Discord
  delivery, and shutdown.
- `deno task publish` passes again; the frontend reaches a fixed point in one stage and the 0.6.4
  VSIX is repackaged. Generated tracked artifacts are unchanged.
