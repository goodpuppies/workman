# Import-facing SML conformance matrix

## Scope

This is the initial audit record required by `S002`, `S003`, and `G2`. It covers every SML semantic
operation used by the first file-module implementation. Workman file discovery, `ModuleId`, graph
ordering, named projection syntax, and initialization-once remain Workman protocol/extensions and
are linked to the SML objects they manipulate.

Definition sources refer to the local Revised Definition in
[`research/The-Definition-of-Standard-ML-Revised`](../../research/The-Definition-of-Standard-ML-Revised/).

## Completion use

Each row moves from its current status to one of:

- conforming;
- accepted restriction;
- accepted definitional extension;
- accepted Workman protocol rule.

No row may close solely because inference succeeds. The listed tests must cover analysis facts, Core
facts, and runtime behavior where the row has a dynamic consequence.
